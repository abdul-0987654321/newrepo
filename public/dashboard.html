How it answers

What the bot knows about the business, and how it should reply in DMs.

What Instagram allows

Limits set by Meta, not by this software.

  • The bot can only reply within 24 hours of someone messaging. It can never message first.
  • Around 200 automated messages per hour, per account.
  • The account must be a professional one — Business or Creator, not personal.
  • Until Meta approves the app, only accounts added as testers can use it.
